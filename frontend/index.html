G-code Compatibility Check

Upload your PrusaSlicer .gcode file to verify it is compatible with your selected printer before submitting a print job.

Step 1 — Select printer

⚠ Required PrusaSlicer Export Settings

Binary G-code must be disabledRequired

  1. Open PrusaSlicer and load your model.
  2. Go to Print Settings → Output options.
  3. Find "Binary G-code" and uncheck it.
    (It is enabled by default in PrusaSlicer 2.7+. If left on, the upload will be rejected.)
  4. Export: File → Export → Export G-code (save as .gcode).

Recommended settings for complete metadata:

  1. Print Settings → Output options → "Add machine limits comments" → ✅ Enabled
  2. Print Settings → Output options → "Verbose G-code" → optional but helpful
  3. Ensure the correct printer profile is selected in the top drop-down before slicing — the profile name is embedded in the G-code and must match your selection above.
